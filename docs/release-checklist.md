# 真机验收清单（发版前手动过一遍）

> 2026-10-20 由 README.md 迁出。发新版前照单全过。


> 更早的条目记录**当时**的行为，未随后续轮次逐条改写；被删掉/重构的功能以各轮章节与
> 最后几项为准。第二十轮起：「保存到文档…」「插入文档卡…」「插入到当前文档」与 dock 的
> 画布操作区（状态行/色板/按钮组）/页脚已整体删除（涉及旧条目 2、5、6、35、39、40、49、56）。
> 第二十二轮起 dock 改原生形态，搜索框删除（以条目 62 为准）。

1. 顶栏图标出得来；点开在页签区打开白板（与文档页签并排）；右键四项菜单（新建 / 最近 / 按路径 / 设置）齐全
2. 画几笔 → `⌘S` → 弹出「保存到文档」：当前文档置顶，「最近编辑」在列；输入关键字能筛、↑↓ 能选、回车能定
3. 选中一篇文档 → 提示「已保存到《…》」；该文档末尾出现图片块；页签标题变文件名、脏点消失
4. 再画一笔 → `⌘S` → 不再弹框、静默覆盖、提示「已保存」；文件名与正文图不变（自动破缓存可见新内容）
5. 走一遍 ☰ 菜单「保存到文档…」：能弹框、选完菜单自动收起；换成另一篇文档保存 → 图片插到新文档
6. 选「仅保存文件，不插入文档」→ 只落盘，提示「已保存（未插入文档）」，不插任何文档
7. 选文档框里按 ✕ / Esc / 点遮罩 → 什么都不发生（不落盘、不插图）
8. 关页签 → 从「最近打开」或文档里的图再开 → 内容还在，能继续编辑
9. 正文里打 `/白板` 执行 → 页签打开且正文残留被清；`⌘Z` 只撤销这次清理（不会回退更早的编辑）
10. 右键 `assets/` 里的 excali 图 → 菜单出现「用 Excali 白板打开」；外链图 / 其它 svg 不出现
11. 用 marketplace 的 `siyuan-embed-excalidraw` 或 excalidraw.com 导出的图，右键能打开
12. 同一张图再点一次入口 → 聚焦已开页签，不开第二份；把页签拖到右侧分屏后再点 → 仍然聚焦它
13. 有未保存改动时页签图标上有小圆点；保存后消失；已落过盘的白板点页签 ✕ → 不弹框、
    静默重存后直接关；没落过盘的新板点 ✕ → 出确认，取消后页签还在
14. 打开白板页签后重启思源 → 页签自动恢复且回到原来的文件（标题是文件名）
15. 设置页三项改完 → 关闭重开插件仍生效（保存目录 / 强调色 / 引导画面）
16. 明暗主题切换画布跟随；开强调色后新建画板第一笔是主题色
17. 移动端（真机或浏览器移动模拟）：页签可开、选文档框可搜可选、双指缩放可用
18. 顶栏/斜杠图标目视验收：线性单色、16px 档与 `iconREReader` 同权重
19. **画板工具栏图标目视验收：矩形/菱形/圆/铅笔/箭头等应为线性描边，不是实心黑块**
20. **画布 UI 全中文目视验收：快捷键列表（帮助）里「从通用元素创建流程图 / 在流程图中导航 /
    裁剪图像 / 完成图像裁剪」为中文；画布空白处右键菜单（切换网格 / 画布与形状属性）；
    元素右键菜单（将选区包裹进画框 / 复制对象链接）；`⌘/Ctrl+P` 弹出的 toast
    「使用 ⌘/ 打开命令面板」也是中文（注意：命令面板本身是上游死功能，弹不出面板，别当验收失败）**
21. 图标（集市 `icon.png`）：160×160、紫底白线、深浅色下都清晰
22. **引导画面出现**：新建白板 → 纸飞机（约 320px 见方）**中心在画布约 1/3 高度处**、水平正中，
    左下一道虚线尾迹圈；下面四行提示 + 三个入口，画面底部留大片空白（对标 Obsidian 那把剑的构图）。
    「按路径打开…」弹思源输入框、「新建白板」再开一张空白板（Windows 显示 `Ctrl+Alt+E`）、
    「帮助」项打开 `?` 弹窗
23. **落笔即消失**：画第一笔 → 引导画面立刻没了；把元素全删空 → 画面又回来（不用重开页签）
24. **开关与主题**：设置里关掉「空画板显示引导画面」→ 重开页签不再出现；切深色主题 →
    纸飞机线条与提示仍看得清（跟 vendor 的 gray-40/60），标题用思源正文色不发灰
25. **窄容器不溢出**：把白板页签拖成窄分屏（或移动端模拟）→ 纸飞机与菜单行随容器收窄、
    不出现横向滚动；手机端只显示三个入口，四行提示收起。再把窗口压矮（≤760px）→
    四行提示同样让位，飞机不被文字顶上去
26. **导出对话框**：☰「导出图片…」或 `⌘⇧E` → 选 PNG/2x → 下载；文件进系统下载目录；切 JPEG 时
    「透明背景」提示用白底；选「复制到剪贴板」后可直接贴到微信/文档里（位图才有复制按钮）。
    `⌘⇧E` **不能**弹出 Excalidraw 自己的导出框
27. **新建即命名（第二十一轮）**：点顶栏图标 / dock「＋」→ 先弹命名框（默认「未命名白板」，
    可改成中文名）→ 确认 → `assets/` 里立刻有这个文件、dock 库里立刻有这一条、页签已开着；
    Esc/✕/遮罩取消 = 什么都不做（不建文件、不开页签）。首笔不画直接关页签 → 文件保留（空白板）
28. **重命名**：☰「重命名」改成新名字 → 提示「已重命名为 …」，旧文件消失、
    最近列表更新；重命名后画布上的新改动会被防抖自动写进新文件（不用手动保存）
29. **防抖自动保存（第二十一轮）**：改几笔什么都不按 → 停手约 1 秒 → 脏点自己消失、
    文件内容已更新；切走窗口 / 切到别的页签也会立即落盘；`⌘S` 立刻落盘不等防抖；
    ☰ 菜单里**没有**「保存」「保存副本…」；设置里**没有**「自动保存」开关（唯一形态）
30. **文件列表打开**：顶栏右键「打开白板…」→ 列出目录内所有 .svg → 点一张能打开；
    空目录提示「目录里还没有白板文件」
31. **图片拖放**：从 Finder 拖一张图进画布 → 落在鼠标位置（可继续拖动）；拖一张 4K 截图
    → 能插入且保存后文件体积没有爆炸（长边被压到 2048）
32. **剪贴板粘贴图片**：截图后（⌘⇧4）在白板里 ⌘V → 图出现在视口中央；粘贴纯文本时仍由
    Excalidraw 正常创建文本元素（不被拦截）
33. **只读 / 禅模式改走右键**：画布空白处右键 → 菜单里有「只读」和「禅模式」（同排还有
    切换网格、对齐吸附、对象统计）；进只读后 ⌘S 仍能保存，再右键退出；禅模式下按 Esc 回常规界面
34. **组件库**：☰ 菜单打开图库 → 添加一个图形到画布 → 保存白板 → 重开页签后图库里
    该项还在（落在 assets/excali-library.json）
35. **☰ 主菜单（第六轮）**：画布右上角**不再有**自绘按钮条（只剩 Excalidraw 自己的「素材库」）；
    菜单顺序为 打开 → 保存（右侧 `Cmd+S`）→ 保存到文档… → 导出图片…（`Cmd+Shift+E`）→
    重命名 → 缩放适应 → 在画布上查找 → 帮助 → 重置画布 → 「Excalidraw 链接」分组 →
    画布背景；五个自绘项**都要有线图标且与内置项左对齐**，文字不能凸出去；
    菜单里**不该再有**「保存到 …」和英文的 `Excalidraw links`；「缩放适应」点一下能回到全部内容
36. **右下角 ➕ 已删、帮助按钮露出（第十一轮）**：画布右下角只剩 Excalidraw 自带的帮助「?」，
    点开是快捷键帮助弹窗、悬停有提示；确认没有圆形 ➕ 再压住它；图片入口仍在：拖放（31）与粘贴（32）
37. **提示气泡**：新建白板后不操作，工具栏下方出现「要移动画布，请按住 空格键…」，
    为居中圆角胶囊样式（明/暗主题下都清晰）
38. **Dock 出现**：左下角出现「Excali 白板」dock（空态：新建/打开两个按钮）；打开一张白板后
    色板 + 操作组出现，头部显示当前文件名
39. **背景色板**：点一个色块 → 画布背景立即变；再点「默认」（带斜线的那个）回到主题默认；
    保存重开后背景仍在
40. **插入到当前文档**：在文档页签里编辑时，点 dock「插入到当前文档」→ 图片块追加到该文档
    末尾；没有正在编辑的文档时提示「没有正在编辑的文档」；白板未保存时提示「请先保存白板」
41. **重置画布**：点「重置画布」→ 弹确认 → 画布清空、文件不动；多张白板同时开时 dock 动作
    只作用于最近交互的那张（开 A 画一笔、再开 B，dock 保存的是 B）
42. **内置脚本安装**：禁用→启用插件 → 提示「已安装 4 个内置脚本到 assets/excali-scripts」，
    思源文件树/资源面板能看到 4 个 .md（可当普通文档改）
43. **运行脚本**：打开一张白板 → ☰「运行脚本…」或 dock「其他 → 运行脚本…」→ 选
    「笔记标题 → 思维导图」→ 画布出现树状导图，提示运行成功（毫秒数）；先在某个文档页签
    编辑，再跑思维导图/表格/流程图脚本 → 读的是那篇文档
44. **onload**：给某个脚本文档头加一行 `@excalidraw-onload` → 关开白板页签 → 该脚本自动跑
45. **自定义脚本**：在思源里新建 `assets/excali-scripts/我的脚本.md`（H1 + ```js 围栏）→
    ☰「运行脚本…」列表里出现并运行；console.log 的内容进开发者工具控制台
46. **安全确认**：脚本能读写画布/读当前文档——只运行自己写的或看懂了的脚本
47. **网格记忆（第十轮）**：任意白板里按 `⌘'`（或画布右键「切换网格」）打开网格 → 关掉页签
    再打开 → **还是网格**；新建白板（从没保存过的空白板）也直接是网格；设置里「默认显示网格」
    跟着变成开；把它关掉 → 之后打开的页签恢复无网格（已开的页签不受影响）
48. **关页签冲刷（第十二轮）**：已落过盘的白板改几笔 → `⌘W`（或标签右键「关闭」、点 ✕）→
    页签直接关、无确认框；重新打开该文件 → 改动都在，且 assets 里留了新一份 `*.svg.bak.svg`
49. **dock 打磨（第十二轮）**：「保存」是主色实心按钮；「其他」组有「打开白板…」（点开出
    文件列表、与顶栏右键同一个）；改一笔 → 文件名下状态行变「有未保存的改动」、保存后变
    「已保存 HH:MM」且不跳版；新建白板标题为「未命名白板」
50. **「默认」背景导出不透明（第十二轮）**：不设画布背景（默认，白底跟随主题）直接画 →
    「导出图片…」不勾「透明背景」→ PNG 是白底（暗色主题下近黑底）而非透明底；
    勾上仍透明；导出的 SVG（内嵌 scene）重新打开仍跟随主题
51. **「打开白板…」选择器（第十三轮）**：打开选择器 → 逐字输入文件名看列表即时收窄；
    中文输入法打拼音期间列表不闪「没有匹配的白板」、上屏后才过滤；`↑↓` 移动、
    `Enter` 选中、`Esc` 取消；已在页签里打开的白板行有「已打开」角标，点它 → 直接聚焦
    那个页签（不新开）；每行悬停有完整路径；时间显示「今天 HH:MM / 昨天 HH:MM /
    MM-DD HH:MM」，跨年的带年份
52. **清空最近记录（第十三轮）**：打开/保存过几块白板后，顶栏图标右键 → 最近区有完整
    路径 tooltip → 点「清空最近记录」→ 再右键，最近区只剩「还没有打开或保存过白板」；
    文件本身都还在（保存目录里没少东西）
53. **保存副本（第十三轮）**：☰ →「保存副本…」→ 输入框默认「原名 副本.svg」→ 确认 →
    提示「已保存副本 xxx」、页签标题变成副本名；原文件内容不变（新旧两份对比都是对的）；
    再画几笔 `⌘S` → 覆盖的是副本，原文件不受影响
54. **Dock 刷新合帧（第十四轮）**：连续拖动/缩放一个元素几秒，左侧 Dock 的文件名与状态行
    不闪不跳、色板高亮不错位；松手后画几笔「有未保存的改动」立刻出现（不等下一帧）；
    切换页签、点色板、关页签后面板内容当场对上（关到最后一页签显示「没有打开的白板」）
55. **脏判定精确化（第十五轮）**：打开一块已有白板，**一笔不动**——页签标题不亮脏点、
    Dock 不显示「有未保存的改动」、直接 `✕` 关闭不弹确认；在保存目录里也没多出 `.bak`
    （等 30s 让定时自动保存跑过一轮再确认）。接着试平移画布、`⌘0` 缩放、换工具、点色板、
    开关网格——都不该亮脏点；画一笔 → 立刻亮；`⌘S` → 回到不亮；再画一笔并立刻切走页签，
    回来仍是脏（保存期间的新改动没被吞掉）。已知代价：`⌘Z` 撤回存盘时的内容后仍显示脏，
    此时 `⌘S` 存一次即可
56. **文档卡（第十六轮）**：三个入口各试一遍——① 从思源文件树拖一篇文档进画布 → 落点建卡
    （多选拖入按 26px 错开）；② 复制文档引用（`siyuan://blocks/…`）在画布 `⌘V` → 视口中心
    建卡（粘贴纯文本仍是文本、画布内编辑文字时粘贴不拦截）；③ ☰「插入文档卡…」与 dock
    「操作 → 插入文档卡…」选一篇文档。卡片是 260 宽圆角矩形、正中文档标题；悬停卡片左上角
    出现链形徽标，点它 → 打开那篇文档（外链卡片点开走系统默认）；拖入已删除的文档 →
    提示「未找到该文档」、不建卡；建完 `⌘S` 保存 → 重开文件卡片还在、徽标仍可点
57. **白板即文档（第十七轮）**：新建白板 → `⌘S` 命名保存 → 文档树「Excali 白板」目录下出现
    同名文档（H1+图片块，图片能随画板保存而刷新）；dock 白板库出现该行（时间/引用数/svg 名，
    tooltip 是 hpath）；**单击**行 → 开画板（再点不双开、只聚焦），**双击** → 开文档本体；
    开画板时行上出现「已打开」徽标，关掉页签徽标消失。搜索框按标题过滤、⟳ 重扫。
    切到该文档（`switch-protyle`）会自动开画板，但**同一篇每次会话只自动开一次**，
    设置里关掉「打开白板文档时自动进入画板」后不再自动开；白板文档在**文档树右键**与
    **文件页签右键**里多出「在画板中打开」，普通文档没有这一项。
    往 `assets` 手工扔一个旧 `excali-*.svg`（没建档的）→ dock 库页脚「未收编 1 个」→
    点「收编」→ 建档绑定开板一步到位、页脚清空。页签里重命名 → 文档属性跟着搬
    （`⟳` 后列表里 svg 名是新的、旧名不再出现在未收编）。首次保存时若无打开的文档，
    建档落第一个笔记本（不崩、只是落点变化）；建档失败只存 SVG，行为回到老版本
58. **复制引用与体检（第十七轮·批4）**：dock 库行**右键** → 两项「复制嵌入引用 / 复制行内引用」，
    粘到文档里分别渲染成嵌入块（`![[块ID]]`，带正文预览）和行内链（`((块ID "标题"))`）；
    ☰「复制此白板的引用」复制嵌入形式，**还没建档的白板**只提示「先建档」、不动剪贴板
    （dock 行右键「建档」，或设置里开「新建时自动建档」）。
    设置页「白板体检 → 开始体检」：一切正常只出 toast；往 `assets` 扔一个没建档的
    `excali-*.svg` → 报告里「孤儿 SVG（未收编）：1」；手工删掉某个白板文档绑的 SVG 再
    `⟳` 前跑体检 → 「断链文档：1」列出文档标题与文件名。连点体检按钮不会并行跑两轮
59. **BAK 纪律与恢复（第十九轮）**：同一块板连续覆盖保存四次 → 保存目录只有
    `.bak.svg` / `.bak2.svg` / `.bak3.svg` 三档滚动（没有 `.bak4`），dock 库里**看不到任何备份档**；
    **清板**（全选删除画布内容）→ 停手约 1 秒或切窗失焦 → 文件不被写成空的（重开仍有内容），
    脏点保持，备份链也不被空内容挤掉；按住画一笔/双击编辑文字期间到自动保存周期不会打断输入。
